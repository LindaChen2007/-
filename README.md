# A股突破策略回测框架

## 策略逻辑
- 信号：昨日收盘在20日均线下方 + 今日收盘站上20日均线 + 成交量放大（量比>1.2）
- 交易：信号触发后次日开盘买入，再下一交易日开盘平仓
- 成本：双边手续费0.03%

## 股票池
贵州茅台、中国平安、宁德时代、比亚迪（2023-2024日线）

## 怎么跑

1. 安装依赖：
pip install -r requirements.txt

2. 打开 run.ipynb，逐个格子运行（或 Kernel → Restart & Run All）

## 项目结构
- data.py：数据获取（akshare接口，含重试）
- factors.py：信号计算（均线+量比+突破）
- backtest.py：回测引擎（次日开盘成交）
- run.ipynb：主程序入口

## 已知局限
- 样本仅4只股票，未做样本外检验
- 未考虑涨跌停无法成交的情况
- 未做行业中性化处理
- 仅供学习研究，不构成投资建议
